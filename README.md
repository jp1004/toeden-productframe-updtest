# TOEDEN ProductFrame (TOEDEN 상품 틀 만들기)

상품 사진과 정보로 상세페이지·영상을 만들고, 아임웹 쇼핑몰에 등록하는 Windows 프로그램입니다.

## 내려받기

오른쪽 **Releases** 에서 가장 위의 최신 버전을 열고, 아래쪽 **Assets** 의 `TOEDEN-ProductFrame-Setup-x.x.x.exe` 를 내려받아 실행하세요.

## 설치할 때 안내

- 설치 파일에 코드 서명이 없어 Windows 가 **"Windows의 PC 보호"(SmartScreen)** 창을 띄울 수 있습니다.
  **추가 정보 → 실행** 을 누르면 설치가 진행됩니다.
- 프로그램은 **라이선스 키**(`WF-XXXX-XXXX-XXXX` 형식)가 있어야 사용할 수 있습니다. 키는 구매하신 곳에서 받으세요. 키 1개당 PC 2대까지 사용할 수 있습니다.
- 인터넷 연결이 필요합니다(라이선스 확인, 무료 음성, AI 글 작성).
- 사용 설명은 설치 후 프로그램 안내와 함께 제공되는 사용설명서를 참고하세요.

## 새 버전 받는 법

Releases 에 새 버전이 올라오면 같은 방법으로 설치 파일을 내려받아 실행하면 기존 설치 위에 업데이트됩니다. 작업 데이터와 설정은 유지됩니다.
